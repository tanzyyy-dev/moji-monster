## 音楽

| ファイル                                   | 用途        | 生成元       | 記録                                     |
| ------------------------------------------ | ----------- | ------------ | ---------------------------------------- |
| `assets/audio/Through_the_Garden_Gate.mp3` | ゲーム内BGM | Geminiで生成 | 生成モデル、プロンプト、生成日時は未記録 |

音源は約61秒、44.1 kHz、ステレオ、MP3（約192 kbps）です。ファイル名は生成時の名前を維持しています。

GoogleのGeminiヘルプでは、Geminiで音楽を生成してMP3として保存できることが案内されています。生成物に関するGoogleの条件はサービスや利用時期によって異なる場合があるため、音源の利用条件は生成時に適用された規約と法令に従います。このプロジェクトのライセンスは、Gemini生成音源について排他的な著作権を主張せず、音源の再利用許諾も付与しません。

- [Geminiで音楽を生成する（Googleヘルプ）](https://support.google.com/gemini/answer/16901237)
- [Google 利用規約](https://policies.google.com/terms)

## ゲーム内の画像

塗り絵テンプレートと基本図形は `src/components/drawing-editor/templates.js` にSVGとして定義しています。画像の絵柄から読み込んだ画像は、プレイヤーが選択したファイルです。

インターフェースで使う Lucide の SVG とライセンスは `assets/icons/` にあります。用紙の表示切替、ペンの太さ、目玉、塗り絵、取り消し、全消去の絵柄は、描画エディタ内の独自 SVG です。
